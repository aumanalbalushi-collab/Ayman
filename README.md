# مدرستي

منصة تعليمية للمعلمين والطلاب تعمل على كل الأنظمة (أندرويد، آيفون، ويندوز، ماك، لينكس) كتطبيق ويب قابل للتثبيت (PWA).

## الميزات

| | المعلم | الطالب |
|---|---|---|
| الفصول | إنشاء فصول، ورمز انضمام لكل فصل، وإزالة طلاب | الانضمام برمز، والمغادرة |
| الدروس | نص، وفيديو (يوتيوب/فيميو يُعرض داخل التطبيق)، وملفات مرفقة | عرض الدروس وتنزيل الملفات |
| الواجبات | إنشاء واجب بموعد نهائي، ثم التصحيح وكتابة ملاحظات | تسليم نص و/أو ملف، والتعديل حتى التصحيح |
| الاختبارات | أسئلة اختيار من متعدد | حل الاختبار مرة واحدة، والتصحيح فوري على الخادم، ثم رؤية الإجابات الصحيحة بعد التسليم |
| الحضور | تسجيل يومي (حاضر/غائب/متأخر/بعذر) | رؤية سجل حضوره ونسبته |
| التقارير | متوسط الدرجات والحضور لكل طالب، وتصدير CSV لـ Excel | درجاته ونسبة حضوره |
| التواصل | إعلانات، ومحادثة فورية للفصل | نفس الشيء |
| الإشعارات | — | تلقائية عند درس أو واجب أو اختبار أو إعلان جديد، أو عند التصحيح |

الأمان مطبّق في قاعدة البيانات نفسها (Row Level Security)، فالطالب لا يرى إلا فصوله وتسليماته، ولا يستطيع قراءة الإجابات الصحيحة أو تعديل درجته حتى لو تجاوز الواجهة.

## التشغيل

### 1. قاعدة البيانات (Supabase، مجانية)
1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. افتح **SQL Editor** والصق محتوى `supabase/schema.sql` ثم اضغط **Run**.
3. من **Project Settings ← API** انسخ `Project URL` و`anon public key`.
4. (اختياري للتجربة) من **Authentication ← Providers ← Email** أطفئ "Confirm email" حتى لا يحتاج المستخدم تأكيد البريد.

### 2. التطبيق
```bash
cp .env.example .env    # ضع فيه الرابط والمفتاح
npm install
npm run dev             # للتطوير على http://localhost:5173
npm run build           # نسخة الإنتاج في dist/
```

### 3. النشر
- **Vercel**: اربط المستودع، وأضف المتغيرين `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات المشروع. ملف `vercel.json` جاهز.
- **Netlify**: مثله. ملف `public/_redirects` جاهز.

### 4. التثبيت على الأجهزة
- **أندرويد / كروم / إيدج (ويندوز، ماك، لينكس)**: افتح الرابط ثم اختر "تثبيت التطبيق" من القائمة.
- **آيفون / آيباد**: افتح الرابط في سفاري ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

## حدود معروفة
- الإشعارات تظهر داخل التطبيق فوراً، وكإشعار نظام عندما يكون التطبيق مفتوحاً في الخلفية. أما الإشعارات والتطبيق مغلق تماماً (Web Push) فغير مضافة بعد، وتحتاج خادماً إضافياً.
- لا يوجد بعد حساب "ولي أمر" أو "مدير مدرسة"، ولا بثّ مباشر للحصص.
- النشر في متجري Google Play وApp Store غير مُعدّ. يمكن لاحقاً تغليف التطبيق نفسه بـ Capacitor.
